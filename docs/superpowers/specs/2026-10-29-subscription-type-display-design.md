# 订阅类型友好显示设计

## 目标

账号卡片中的订阅类型不再直接展示后端原始标识（例如 `self_serve_business_prolite`），而是展示可读名称；鼠标悬停时仍能看到原始值，便于排查和核对。

## 交互与文案

- `self_serve_business_prolite` 显示为 `Business 高级版`。
- 徽章悬停提示同时包含友好名称和原始值：
  - `订阅类型：Business 高级版`
  - `原始订阅类型：self_serve_business_prolite`
- 未知值不丢失信息：将下划线/连字符转换为空格后显示，原始值仍放在悬停提示中。
- 空值、纯空白值继续不显示订阅徽章。
- 徽章保留可访问名称，避免仅依赖颜色或鼠标悬停才能理解。

## 实现边界

- 仅修改前端显示，不修改数据库、后端 API 或保存的原始订阅值。
- 新增纯函数模块负责原始值到显示值/提示文案的转换，便于单元测试和后续扩展映射。
- 账号卡片继续复用现有 `officialSubscriptionType` 的读取逻辑。

## 验证

- 单元测试覆盖已知 `self_serve_business_prolite`、未知带下划线的值和空值。
- `AccountsScreen` 测试覆盖：显示友好名称、`title` 包含原始值、原始长字符串不再直接出现在可见文本中。
