ai-switch 诊断采集

用于排查「Codex 不显示思考 / 首字卡顿」。它通过本机 Web 服务读取实时日志里上游原始报文与客户端最终报文，两者一比就能确定是上游没发、还是我们把它丢了。

1. 连接本地 Web 服务

未测试
端口和令牌在哪？
  1. 打开 ai-switch → 设置 → Web 服务，确认已启动，页面上就有「服务端口」和「访问令牌」。
  2. 也可以直接打开数据目录下的 web-service.json（Windows：%USERPROFILE%\.ai-switch\web-service.json；macOS：~/.ai-switch/web-service.json），把里面的 port 和 token 填上来。

2. 抓取（请在窗口内复现问题）

实时日志只保留最近 100 条，所以要在抓取期间到 Codex 里重新发一次「不显示思考」的那类提问。 抓取会每 2 秒拉一次，按请求 id 去重累积。
未开始
0已捕获
0上游发了/客户端没收到
0两边都有
0两边都没有
0报文被截断，无法确认
0报文缺失
时间平台桥上游主机模型耗时判定

3. 导出

导出的文件里，client_request / upstream_request 会包含你这几轮的对话内容。 介意的话可以先自己看一眼再决定发不发。
