## 本机踩坑（新发现，与既有记忆冲突的要改）

- ⚠️ **`sed -i` 在本机 Git Bash 会把 CRLF 文件的 CR 全部剥掉**。`tauri.conf.json` 76 CR → 0 CR，
  `git diff --numstat` 从应有的 `1 1` 变成 `76 76`。既有 MEMORY.md 写「用 `sed -i 's/$/\r/'` 补回」，
  但更稳的是**别用 sed**：改用 Python 按字节处理（`d.replace(b'\n', b'\r\n')`），并先做等价预校验
  （`HEAD 版本.replace(b'\r\n', b'\n').replace(旧版本号, 新版本号) == 当前文件`）。
- **`src-tauri/Cargo.lock` 有 `diff: unset` + `linguist-generated` 属性** → git 把它当二进制，
  `git diff --stat` 显示 `Bin 179119 -> 179119 bytes`、numstat 是 `- -`。**这是正常的**，不是文件被写坏。
  另外 `Cargo.lock` 里 `version = "0.10.6"` 有 3 处：`ai-switch` 自己 + `blake2` + `md-5`（后两个是无关 crate），
  改版本号要用带 `name = "ai-switch"` 的上下文匹配，别全局替换。
- 发布前 6 项检查脚本：`.workbuddy-ai/tmp/release-checks.sh`（gitignore 内）。
