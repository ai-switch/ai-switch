# 2026-09-26

## 排查「anyrouter 测试接口报错，但 Claude 客户端能通」——结论：不是缺字段，是 anyrouter 1M 通道当前不可用

用户原话：「我发现Claude客户端是能通过ai-switch访问anyrouter的，但是ai-switch自己的测试接口还是报错，你再检查是否是测试比透传少什么字段？」

### 结论（有硬证据）

**测试接口没有比透传少任何字段。** anyrouter 的 Claude 通道此刻对**所有声明 1M 的请求**返回 503，
包括一个和真实 Claude Code 流量逐项同形的请求（真实 UA、真实 10 标记 beta、`stream: true`、
`tools`、88KB body、真实 `x-claude-code-*`/`x-stainless-*`）。

### 决定性对照（同一请求形状，两个中转站）

```
https://anyrouter.top      claude-opus-5-5  non-stream  HTTP 503  0.6s  {"error":{"message":"Service Unavailable",...}}
https://api.justwoker.icu  claude-opus-4-8  non-stream  HTTP 200  2.9s  {"content":[{"text":"ai-switch-ok",...}]}
https://anyrouter.top      claude-opus-5-5  stream      HTTP 503  0.6s
https://api.justwoker.icu  claude-opus-4-8  stream      HTTP 200  3.0s  event: message_start
```

→ 请求形状没问题（换健康中转站即 200）。**anyrouter 才是坏的那一侧。**

### anyrouter 现在的实际行为（交错重复、非限流）

| `anthropic-beta` | 结果 |
|---|---|
| 不带 | HTTP 400 `{"error":"1m 上下文已经全量可用，请启用 1m 上下文后重试"}` |
| `claude-code-20250219` | 同上 400 |
| `interleaved-thinking-2025-05-14` | 同上 400 |
| `...,context-1m-2025-08-07` | **HTTP 503 `Service Unavailable`** |

即：**该 key 的每个模型都要求声明 1M；一旦声明就 503。** 连 `claude-3-5-sonnet-20241022` 也是同一个 400。
`GET /v1/models` → 200（key 有效）；`claude-opus-4-6` → 400「已下线，请切换到 claude-opus-4-7」
（业务逻辑在跑，说明请求确实到达了 anyrouter）。

### 探针为什么会拿到 520 而不是 503

探针 body 比我的手写请求多一个 `metadata.user_id`（JSON 对象字符串）。
带 1M 声明时：**有该 metadata → 520；没有 → 503**（`ab_shuffle` 3 轮不同位置、`ab_metadata` 3 轮，均稳定）。
真实客户端发的 `metadata.user_id` 形状与探针**完全相同**（从一条未截断的 justwoker 日志取到：
`{"device_id":"242c87a9…","account_uuid":"","session_id":"…"}`），所以这不是「探针多/少了字段」。

### 工具/查询方法（可复用）

- 探针结果落在 **`usage_events`**（不是 live log）：`source_label='route_pool_model_test'`，
  `metadata_json` 里有 `status/success/duration_ms/error_message/target_url`。
  单账号探针**不写 live log**（`via_route_proxy=false`）。
- live log 的 `upstream_request` / `client_request` 会被**截断在 63734 字符**，
  `truncated: true` + `truncated_stages` 标出来；`messages` 太大时后面的 `model`/`stream`/`tools` 看不到。
  用 `json.loads(..., strict=False)` 读外层，body 只能当字符串做子串定位。
- 归档 `*.jsonl.br` 用 `brotli` 解（本机 Python 3.13 有 1.2.0，3.12 没有）。
- `mask_secret` = `***` + 末 4 字符 → 可用来核对 DB 里的 key 与日志里的是否同一个。
- 直接打中转站做对照时**先 `unset HTTP_PROXY HTTPS_PROXY http_proxy https_proxy ALL_PROXY all_proxy`**
  （应用侧 `proxy_enabled: false`，直连）。
- 临时脚本（gitignore 内）：`.workbuddy-ai/tmp/ab_anyrouter.py`（头 A/B）、`ab_body.py`（body 矩阵）、
  `ab_size.py`（尺寸）、`ab_metadata.py`（metadata 交错）、`ab_shuffle.py`（打乱顺序）、
